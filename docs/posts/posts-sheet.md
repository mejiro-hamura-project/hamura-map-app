# 口コミをGoogleスプレッドシートで管理する

アプリの「投稿」タブで投稿された口コミを、Googleスプレッドシートに集めて管理します。
不適切な投稿は、スプレッドシートでセルを消すだけでアプリから消せます。

## しくみ

| 動き | 内容 |
| --- | --- |
| 投稿したとき | アプリからシートに1行追加されます（投稿ID・投稿日時・投稿先・投稿者ID・本文） |
| アプリでの表示 | アプリはシートの内容を読み込んで表示します。開いたとき・画面に戻ったとき・1分ごとに読み直します |
| 消すとき | **「本文」のセルを選んで Delete キーで消す**か、行ごと削除すると、その口コミはアプリに出なくなります |
| いいね | 「いいね」タブに「どの口コミに・どの端末が」押したかを1行ずつ記録し、アプリは読み込むときに数えて表示します。同じ端末が同じ口コミに押せるのは1回までで、もう一度押すと取り消し（行が消える）です |

- 消してからアプリに反映されるまで、遅くとも約1分です（アプリを開き直すとすぐ反映）。
- 本文を消した行は、シートには残ります（記録として残したくない場合は行ごと削除してください）。
- 投稿者名は、端末ごとに自動で決まる架空のニックネームです。シートの「投稿者ID」は端末ごとのランダムな値で、個人を特定する情報は含みません。
- 口コミを消すと、その口コミの「いいね」もアプリに出なくなります（「いいね」タブの行は残ります）。

## 設定手順（最初に1回だけ）

### 1. スプレッドシートとApps Scriptを用意する
1. Googleドライブで新しいスプレッドシートを作ります（名前は自由。例：「市民祭り 口コミ管理」）。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から入っているコードをすべて消し、[posts-sheet.gs](posts-sheet.gs) の中身を貼り付けて保存します。

### 2. Webアプリとして公開する
1. Apps Script の画面右上の「デプロイ」→「新しいデプロイ」を選びます。
2. 種類の歯車から「ウェブアプリ」を選びます。
3. 次のように設定して「デプロイ」を押します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 初回はGoogleアカウントの承認を求められるので、許可します。
5. 表示される「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピーします。

最初の投稿があると「口コミ」タブが、最初の「いいね」があると「いいね」タブが、シートに自動で作られます。

### 3. アプリにURLを設定する
- **ローカルで試すとき**：`app/.env.local` に次の1行を書き、`npm run dev` を起動し直します。
  ```
  VITE_POSTS_API_URL=https://script.google.com/macros/s/…/exec
  ```
- **公開しているアプリ（Cloudflare）**：Cloudflare のビルド設定の環境変数に `VITE_POSTS_API_URL` を追加し、再デプロイします。値はビルド時に埋め込まれるため、設定しただけでは反映されません。

URLを設定しない場合、口コミはその端末の画面内だけに表示され、再読み込みで消えます（シートには送られません）。

## うまくいかないとき

| 症状 | 原因と直し方 |
| --- | --- |
| 開発者ツールに `401 (Unauthorized)` | デプロイの「アクセスできるユーザー」が「全員」になっていません。「Google アカウントを持つ全員」ではなく「全員」にして、デプロイを更新します |
| 開発者ツールに `blocked by CORS policy`、またはURLに `…/macros/s/https://…` | `.env.local` のURLが二重になっています。`VITE_POSTS_API_URL=` の後ろに、コピーしたURLを1回だけ書きます |
| URLの最後が `/exec/exec` や `/execs` | 余分な文字が付いています。URLは `/exec` で終わる形にします |
| 設定したのに何も変わらない | `.env.local` を変えたら、`npm run dev` を止めて起動し直します。古い `npm run dev` が別のウィンドウで動いていたら止めます |
| URLが正しいか確かめたい | ブラウザのシークレットウィンドウでURLを開き、`{"posts":[...]}` のような文字が出ればApps Scriptは正常です |

## 注意

- Apps Script のコードを直したとき（「いいね」に対応した版に差し替えたときを含む）は、「デプロイ」→「デプロイを管理」→ 編集（鉛筆）→ バージョン「新バージョン」で更新してください。新しいデプロイを作るとURLが変わってしまいます。
- WebアプリのURLを知っていれば誰でも投稿を送れる仕組みです。本文は200文字まで、各項目は100文字までに切り詰め、
  数式として動かないように保存しています。荒らしなどが起きた場合は、シートで消して対応してください。
- `VITE_*` の値はブラウザに配信されるアプリの中に含まれます。秘密にすべき値（パスワード等）は設定しないでください。
